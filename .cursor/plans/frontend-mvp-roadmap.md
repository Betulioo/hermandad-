# Frontend MVP Roadmap

## Objetivo
Construir un frontend mínimo para validar el backend de la app web de la parroquia Santa Maria la Antigua.

## Fases
1. Setup técnico y estructura base
2. Layout + Home
3. Páginas públicas: avisos, horarios, productos, rutinas
4. Login
5. Admin mínimo de avisos

## Restricciones
- No hacer panel admin complejo
- No hacer ecommerce completo
- No hacer registro público
- No hacer recuperación de contraseña
- Priorizar integración real con la API
